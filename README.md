# Java Practice Programs

This repository contains a set of simple Java programs focused on object-oriented programming (OOP), especially inheritance and class relationships.

## Project Overview

The programs in this repo demonstrate how classes can inherit behavior and properties from parent classes, and how objects of derived classes can call methods from multiple levels of the hierarchy.

## Included Programs

- `Company.java` — demonstrates multilevel inheritance using `Supervisor`, `Employee`, and `Subordinate`
- `Multilevel.java` — demonstrates inheritance across three classes: `A`, `B`, and `C`
- `VehicleTest.java` — shows a `Vehicle` parent class with `Car` and `Bike` subclasses
- `MobileTest.java` — demonstrates inheritance with a `Mobile` base class and specialized subclasses

## How to Run

1. Make sure Java is installed on your system.
2. Open a terminal in the repository folder.
3. Compile a Java file:

```bash
javac Company.java
```

4. Run the compiled program:

```bash
java Company
```

You can replace `Company` with any other class name such as `Multilevel`, `VehicleTest`, or `MobileTest`.

## Learning Focus

These examples cover:

- Inheritance
- Multilevel inheritance
- Method calls from parent to child classes
- Basic Java class design
- Object creation and usage
